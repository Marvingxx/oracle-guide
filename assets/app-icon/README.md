# Oracle Layout app icon

The Oracle app tile, like every Oracle app: a rounded square in the app's colour (`#e0306f`, rose) with the
Oracle four-pointed star and the letters "La". Until 28/10/2026 the app was Oracle Brand Guide,
"Bg" on `#1d1d1b`.

Drawn by `Oracle-suite/tools/make_app_icon.py`, which writes the SVGs, the 1024 px PNG, the `.ico`, the
`.icns` and the `hicolor/` sizes.
