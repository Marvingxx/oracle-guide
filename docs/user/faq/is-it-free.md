---
title: Is Oracle Layout free?
description: Oracle Layout is free and open source, with no subscription, licence server or telemetry.
order: 10
verified: 0.7.1
---

Yes. Oracle Layout is free. It has no subscription, no licence server and no telemetry.

The code is open source under your choice of the [MIT](https://github.com/Marvingxx/oracle-guide/blob/main/LICENSE-MIT) or [Apache-2.0](https://github.com/Marvingxx/oracle-guide/blob/main/LICENSE-APACHE) licence. Oracle Layout is in pre-alpha, so some InDesign features are not there yet. The list of known gaps is in [docs/gaps.md](https://github.com/Marvingxx/oracle-guide/blob/main/docs/gaps.md) in the repository.
